## State

- **It compiles.** All 55 fixtures and the runtime pass through the Protheus
  compiler without errors.
- **It runs.** `54_selftest` performs 71 pure-computation checks and
  `55_envtest` performs 23 over a work area, a text file and the
  preprocessor. All pass.
- **None of it is real code.** The fixtures were written by whoever wrote the
  transpiler, and not one line has ever run against a genuine codebase, in
  production, or near customer data.
- It has never been used on a real codebase, nor near customer data.
- The test suite asserts that the transpiler emits what it emitted. It cannot
  assert that the result does what the source says. A bug of that shape was
  found late: invalid output recorded as expected, passing for as long as
  nobody looked.

**Compiling is not working. Assume the generated code is wrong until you have
run it and checked it yourself.**
